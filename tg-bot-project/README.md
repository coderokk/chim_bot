# tg-bot-project

## Описание проекта
Данный проект представляет собой Telegram-бота, который управляет задачами, аккаунтами и реакциями на посты. Бот предоставляет пользователям возможность создавать задачи, управлять аккаунтами и отправлять реакции на заданные ссылки.

## Структура проекта
```
tg-bot-project
├── src
│   ├── bot.py                  # Точка входа для бота
│   ├── handlers                 # Обработчики команд
│   │   ├── admin.py            # Обработчики админ-панели
│   │   ├── tasks.py            # Обработчики задач
│   │   ├── accounts.py         # Обработчики аккаунтов
│   │   └── reactions.py        # Обработчики реакций
│   ├── models                   # Модели данных
│   │   ├── task.py             # Модель задачи
│   │   ├── account.py          # Модель аккаунта
│   │   └── user.py             # Модель пользователя
│   ├── services                 # Сервисы для бизнес-логики
│   │   ├── task_service.py      # Логика управления задачами
│   │   ├── account_service.py   # Логика работы с аккаунтами
│   │   └── reaction_service.py  # Логика отправки реакций
│   ├── utils                    # Утилиты
│   │   ├── validators.py        # Валидация входных данных
│   │   └── keyboards.py         # Определение клавиатур
│   └── config.py               # Конфигурации бота
├── requirements.txt             # Зависимости проекта
├── README.md                    # Документация проекта
└── .env                         # Переменные окружения
```

## Установка
1. Клонируйте репозиторий:
   ```
   git clone <URL>
   ```
2. Перейдите в директорию проекта:
   ```
   cd tg-bot-project
   ```
3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Использование
1. Настройте файл `.env`, добавив необходимые токены и пароли.
2. Запустите бота:
   ```
   python src/bot.py
   ```
